# Tactic — Mask Plugin (Minecraft 26.2, Gradle)

Плагин на **маску**, которая на 30 минут полностью скрывает ник игрока под `????`.

## ✅ Где скрывается ник
- **Таб-лист (TAB)** — `????`
- **Чат** — `<????> сообщение`
- **Над головой** (ванильный неймтег скрыт, вместо него арморстенд c `????` — следует за игроком, приседает, скрывается в инвизе/спекте)
- **Сообщения о смерти/убийстве** — даже если замаскированный убьёт кого-то мечом, луком, трезубцем или снарядом — в death message везде будет `????`
- **Сообщения входа / выхода / кика** — `???? вошёл в игру`
- При **перезаходе** и **смене мира** маска продолжает действовать
- **По истечении 30 минут** всё автоматически возвращается как было

## 🎭 Предметы плагина

### 📄 Маска (`/givemask`)
- Выглядит как лист бумаги с именем `§5Маска`
- **ПКМ по воздуху/блоку** — активирует маску на 30 минут, после чего **предмет исчезает** (расходуется)

### ✂️ Ножницы разоблачения (`/giveshears`)
- Особые ножницы с именем `§cНожницы разоблачения`
- **Ударьте ими замаскированного игрока** — с него сорвётся маска (ножницы тоже расходуются)
- Урона не наносят, если цель не замаскирована — выводят подсказку
- Игроков с правом `tactic.mask.protected` разоблачить нельзя

## ⌨️ Команды

| Команда                 | Право                  | Что делает                                 |
|-------------------------|------------------------|--------------------------------------------|
| `/givemask [игрок] [N]` | `tactic.give.mask`     | Выдать N масок (по умолчанию 1)            |
| `/giveshears [игрок] [N]`| `tactic.give.shears`  | Выдать N ножниц (по умолчанию 1)           |
| `/unmask <игрок>`       | `tactic.unmask`        | Досрочно снять маску с игрока              |
| `/maskreload`           | `tactic.admin`         | Перезагрузить `config.yml`                 |

Права на выдачу и досрочное снятие по умолчанию у операторов. В таб-кодополнении IDEA/сервер подсказывает ники онлайн-игроков.

## ⚙️ Конфиг (`plugins/Tactic/config.yml`)

```yaml
mask-name: "????"
mask-duration-seconds: 1800           # 30 минут
mask-name-color: "§7"                 # серый
mask-item-model-data: 1001            # CustomModelData для маски
shears-item-model-data: 1002          # CustomModelData для ножниц
```

При первом запуске `config.yml` генерируется автоматически.

## 🔨 Сборка (Gradle)

Открой папку `IdeaProjects/Tactic` в IntelliJ IDEA как Gradle-проект и выполни:

```bash
./gradlew jar        # Linux/macOS
gradlew.bat jar      # Windows
```

Готовый JAR лежит в `build/libs/Tactic.jar` — закинуть его в папку `plugins` сервера **Spigot / Paper 26.2**.

## 🧠 Технические детали
- Пакет: `org.examplee.tactic`, главный класс: `TacticPlugin extends JavaPlugin`
- Наши предметы помечаются через `PersistentDataContainer` (не только по `CustomModelData`) — даже если игрок переименует предмет в наковальне, плагин всё равно узнает его
- Арморстенды автоматически очищаются при выключении плагина и при выходе игрока (нет мусора в мире)
- Работает тик-защита, возвращающая `????` в таб/displayName каждую тику — другие плагины не перетрут ник
