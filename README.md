# SmakGlad

Кастомные плагины Minecraft (Paper) для сервера.

| Модуль | Описание |
|---|---|
| `PalePlugin` | «Бледный лес»: заражение биомов, обереги, карта заражения, очищающие предметы |
| `LeperClass` | Класс прокажённых: заражение, благословения, зонт, чих, солнце, инверсия зелий |
| `Smakenchant` | Кастомные зачарования (двойной прыжок + повышение макс. уровня ванильных) |
| `Tactic` | Маска, боевые предметы, кальян, ритуальный костёр (26.2) |
| `dvarf` | Дворфийская раса (Purpur 1.21.x) |
| `guardianClassPlugin` | Класс хранителей |
| `vampirest` | Раса вампиров (PlaceholderAPI) |

## Сборка

Все модули — стандартные Gradle-проекты на **Kotlin DSL** (`build.gradle.kts`),
сборка на **JDK 25** (toolchain, авто-загрузка Gradle'ом).

```bash
cd <модуль>
./gradlew build     # jar появится в build/libs/
```

В IDEA: открыть папку модуля как Gradle-проект (File → Open → выбрать `build.gradle.kts`),
IDE подхватит toolchain JDK 25 автоматически.
