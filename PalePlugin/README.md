# PalePlugin — «Бледный лес»

Плагин для Paper 1.21.x: постепенное заражение карты «бледным лесом» — источники разрастаются по чанкам,
блоки перекрашиваются в бледные материалы, биомы переключаются, заражённые зоны ставят дебаффы игрокам.

## Возможности

- Разрастание инфекции от источников (настраиваемая скорость, радиусы, стадии, лимиты на мир).
- Обереги (wards) — защита территории от заражения; хранение в `wards.yml`.
- Очищающие предметы: соль, святая вода, огниво (очки-очиститель), Палочка заразы (infection wand).
- Карта заражения (`/palespread map`) — цветная карта уровней заражения в чате.
- Дебаффы в заражённых зонах по стадиям (замедление, слабость, усталость, тьма).
- Сохранение источников и биомов между сессиями (`wards.yml`, `biomes.yml`).
- Админ: `/palespread gui`, purge (очистка области), выдача предметов игрокам.
- Мягкая зависимость от `LeperClass` (интеграция: чих/заражение прокажённых может заражать мир).

## Команды

```
/palespread on|off          — вкл/выкл разрастание
/palespread speed <1..5000> — множитель скорости
/palespread info            — состояние
/palespread map [r]         — карта заражения (радиус в чанках)
/palespread give <salt|holywater|ward|flint|purge|map|wand> <ник> [кол-во] [r|uses]
/palespread contract <start|status|cancel|claim>
/palespread gui             — админ-меню
```

Права: `pale.admin` (op), отдельные права `pale.command.palespread.*`, `pale.use.*`, `pale.effect.immune`.

## Сборка (Gradle, Kotlin DSL)

Требуется JDK 25 (Gradle toolchain подтянет её автоматически, если JDK 25 не установлен).

```bash
./gradlew build        # Linux/macOS
gradlew.bat build      # Windows
```

Результат: `build/libs/PalePlugin.jar` — кладётся в `plugins/` сервера Paper 1.21.x.

Тестовый сервер (Paper 1.21.1, плагин run-paper):

```bash
./gradlew runServer
```

Сервер стартует в папке `run/`. Если `../LeperClass/build/libs/LeperClass.jar`
уже собран — он подхватится автоматически (softdepend в обе стороны).

## Настройки

Все настройки — в `plugins/PalePlugin/config.yml` (создаётся при первом запуске):
секции `spread`, `biome`, `effects`, `items`, `admin`.
