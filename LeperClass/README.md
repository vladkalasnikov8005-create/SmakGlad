# LeperClass — класс Прокажённых

Плагин для Paper 1.21.x: раса «прокажённых» — заражение, стадии, благословения, солнце
сжигает прокажённых (как вампиров), зонт защищает от солнца, чих заражает рядом стоящих,
бомба и посох чумы, инверсия зелий, меню и админ-команда.

## Возможности

- Добавление/снятие класса прокажённого (`/leper add|remove <ник>`), статус (`/leper status`).
- Стадии заражения с прогрессом во времени; эффекты по стадиям.
- Благословения: `/leper bless|unbless` (в т.ч. «danger»-благословение, ускоряющее заражение мира).
- Чих (`/leper sneeze`) — подбрасывает цель и заражает рядом; кулдауны из `config.yml`.
- Зонт: держится в offhand, блокирует солнце, имеет прочность.
- Бомба чумы и посох чумы — заражающие предметы (рецепты включены).
- Солнце: прокажённые горят на свету (кроме бледной поверхности/под зонтом).
- Инверсия зелий для прокажённых (лечение ранит, яд лечит).
- Меню прокажённого (`/leper` или правый клик), миграция старых предметов (`/leper migrateitems`).
- Интеграция с `PalePlugin` (softdepend): действия прокажённых заражают «бледный лес».
- Баланс: деньги/штрафы за заражение, бешенство при голоде.

## Команды

```
/leper menu|add|remove|bless|unbless|sneeze|status|migrateitems
```

Права: `leper.admin` (op), `leper.sneeze` (op).

## Сборка (Gradle, Kotlin DSL)

Требуется JDK 25 (Gradle toolchain подтянет её автоматически, если JDK 25 не установлен).

```bash
./gradlew build        # Linux/macOS
gradlew.bat build      # Windows
```

Результат: `build/libs/LeperClass.jar` — кладётся в `plugins/` сервера Paper 1.21.x.

## Настройки

`config.yml` в корне плагина (выдаётся в jar): балансы, кулдауны чиха, инверсия зелий,
минуты фаз заражения и т.п.

## Примечание

Код восстановлен (декомпилирован CFR 0.152) из исходного jar 1.2.0 и проверен:
синтаксис, структура пакетов, имена методов, все строковые константы (сообщения, ключи
конфига, права) совпадают с оригинальным байткодом (Java 21). Байткод новой сборки —
также уровень Java 21 (`options.release 21`), поэтому jar работает и на серверах на Java 25.
